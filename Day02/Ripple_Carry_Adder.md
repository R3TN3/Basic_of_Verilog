# Ripple Carry Adder
리플 캐리 가산기(Ripple Carry Adder)는 가신기를 연결하여 다비트를 병렬로 더하는 병렬 가산기의 가장 단순한 형태이다.

## Input & Output (입출력)
- 입력: A(4bit), B(4bit)
- 출력: S(Sum, 4bit), C(Carry, 1bit)
